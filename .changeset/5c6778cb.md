Add the lexeme family — `tok(p)` and `keyword(s)` — for token-aware grammars. `tok(p)` runs `p` then consumes trailing whitespace, preserving `p`'s `.Output` type. `keyword(s)` matches the exact literal `s` followed by a non-identifier byte (or EOF), then consumes trailing whitespace; the boundary check distinguishes keyword tokens from prefix matches (`keyword("if")` rejects `"ifx"`). Identifier-continuation chars are `[a-zA-Z0-9_]` per the default lexer profile (shared with the future `identifier` parser in #48 via a colocated `internal.zig`). Both are zero-allocation; `keyword`'s `actual` borrows from `state.input` on err. Compile-time error if the keyword literal is empty.
