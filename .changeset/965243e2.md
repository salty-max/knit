Add `Diagnostic(T)` + `Parser(T).runDiag` / `runDiagArena` for multi-error reporting. The parser stream collects every `recoverAt`-swallowed err (with `severity = .recovered`) alongside the value (or fatal err) — recovery-driven grammars (asm, Gero language compilers) can now surface every malformed construct in a single parse, not just the first failure. The plain `.run` / `.runArena` paths leave the recovery sink unset, so existing single-error grammars are unaffected (zero perf cost). `recoverAt` was updated to push to the sink when present; otherwise it drops the err exactly as before. `ParseState` gains a `recovered_errs: ?*std.ArrayList(ParseError) = null` field. CLAUDE.md gets a new "Multi-error diagnostics" subsection.
