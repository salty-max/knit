Add the lang family — `identifier`, `intLit`, `floatLit`, `signed`, `stringLit` — under a new `parsers/lang/` dir. Generic language primitives reusable across grammars (asm, Gero language). All but `stringLit` are zero-allocation (returns borrow into input or an unboxed numeric); `stringLit` allocates the decoded slice via `state.allocator` (canonical arena-per-parse cleanup) since escape processing transforms input bytes.

- `identifier()` — letter/underscore + `[a-zA-Z0-9_]*`
- `intLit()` — unsigned `i64` in decimal / `0x` / `0o` / `0b`, with identifier-byte boundary
- `floatLit()` — unsigned `f64` with optional fraction/exponent (bare integers fall through, no double-counting with `intLit`)
- `signed(p)` — wrap any signed numeric parser to admit `-`/`+` prefix; comptime-rejects unsigned/non-numeric `T`
- `stringLit()` — `"..."` with `\n \t \r \\ \" \xHH` escapes; returns the decoded slice

Shared internal helpers (`isIdentStart`, `isIdentContinuation`, `isDigitInBase`) live in `lang/internal.zig`; identifier-continuation alignment with `keyword` is preserved by re-exporting from `lexeme/internal.zig`.
