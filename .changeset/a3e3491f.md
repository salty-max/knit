Fix critical bug: backtracking combinators (`choice`, `Parser(T).lookAhead`, `possibly`) saved `state.index` and `state.bit_offset` after PR #122 but did NOT save/restore the `recovered_errs` list length added in PR #112. Recovered errs pushed by `recoverAt` inside an alternative that the combinator later discards stayed in the diagnostic sink, polluting `runDiag`'s output with errs from paths the parser never actually took. Same class of latent bug as the bit_offset miss — newly added `ParseState` field that pre-existing combinators forgot to handle. All three now save `list.items.len` before running the inner and `shrinkRetainingCapacity` to that length on rollback. Regression tests added.
