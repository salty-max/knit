Add `possibly(p)` — make a parser optional. Returns `Parser(?T)` (Zig optional, idiomatic): inner success wraps the value in `?T` and advances the cursor; inner failure rolls back to the pre-`possibly` cursor and returns `ok` with `null`. Always succeeds. Type inferred from the parser itself. Composes naturally with `sequenceOf` (optional fields), `many` (collecting `?T`), and `.map` (e.g. `orelse default` to flatten).
