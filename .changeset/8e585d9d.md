Add `peek()` — return the byte at the cursor without advancing. Byte-level (does NOT decode UTF-8 — returns the leading byte of multi-byte codepoints, or invalid bytes verbatim). EOF yields `kind = .incomplete` with `parser = "peek"`. Distinct from `lookAhead(p)`: `peek` is a primitive that reads one byte directly; `lookAhead` wraps an arbitrary parser and restores the cursor on success.
