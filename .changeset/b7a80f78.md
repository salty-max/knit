Add the `sepBy` family — `sepBy(sep, p)`, `sepByOne(sep, p)`, `sepEndBy(sep, p)`, `sepEndByOne(sep, p)`. Each matches `p` separated by `sep`; the value list collects only `p`'s outputs (separators are discarded). The `*One` variants require at least one match and propagate the inner parser's error verbatim. The `sepEnd*` variants consume an optional trailing separator, while `sepBy` / `sepByOne` leave the trailing separator in the input. All four use type inference (`sepBy(sep, p)` infers value/sep types from the parsers themselves) and share collection logic in a colocated `internal.zig`.
