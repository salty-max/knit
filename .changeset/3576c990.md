Add `choice(T, parsers)` — first-success-wins alternative across a homogeneous slice of `Parser(T)`. Every alternative full-backtracks (cursor restored to the pre-`choice` position before each next attempt; no `try` / `cut` / commit). On total failure, returns the inner error that reached the furthest cursor; ties are broken by earliest position in the list, so the diagnostic preserves the most-progressed branch's message. Compile-time error if `parsers.len == 0`.
