Add top-level barrel exports `linecol` and `LineCol` — the byte-offset → 1-indexed `(line, col)` helper for diagnostic display, accessible directly from `parsil` (was only via `parsil.core.linecol` before). Behavior expanded to recognise all three line-break conventions (LF, CRLF, classic-Mac CR-only) so the helper produces correct positions regardless of the OS that produced the input. Implementation moved from `core.zig` to `util/linecol.zig` per the CLAUDE.md `src/util/` convention for non-parser helpers; `core` re-exports for the existing `formatParseErrorPretty` callers; `parsil` re-exports through `core` (Zig 0.16 forbids the same file from belonging to two modules).
