Add the binary numeric primitive family — 18 fixed-width parsers (`u8 / i8 / u16le / u16be / i16le / i16be / u32le / u32be / i32le / i32be / u64le / u64be / i64le / i64be / f32le / f32be / f64le / f64be`) under `parsers/binary/`. Namespaced under `parsil.binary.` so the parser names don't shadow Zig's primitive type identifiers at the top level (e.g. `P.binary.u16le()`). All read via `std.mem.readInt` / `@bitCast` (with safety justification), no alignment assumptions, explicit endianness per parser. EOF before the required width yields `kind = .incomplete`. The `binary.Endian` enum is also re-exported for callers that want to spell endianness comptime without importing `std`.
