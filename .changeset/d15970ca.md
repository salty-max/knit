Add the char family of UTF-8-aware primitives: `char(c)`, `anyChar()`, `satisfy(predicate, name)`, `oneOf(set)`, `noneOf(set)`. All return `Parser(u21)` (codepoint), advance by the codepoint's byte width, and emit `kind = .lexical` on invalid UTF-8 / `kind = .incomplete` on EOF mid-codepoint. Adds shared `core.decodeNext(state)` helper plus `Utf8DecodeError` / `Utf8DecodeResult` types. First parser to use the nested layout (`src/parsers/char/<name>.zig`) unlocked by the named-core-module chore.
