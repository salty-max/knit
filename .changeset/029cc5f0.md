Add `sequenceOf(parsers)` — run a heterogeneous comptime tuple of parsers in order and collect their success values into a tuple of matching types. Each inner parser keeps its own value type via comptime tuple manipulation; no `*anyopaque`, no runtime type erasure. On any inner failure, returns the error unchanged with the cursor at the failing position (backtracking is a `choice` concern, not a `sequenceOf` one). Also exports the `TupleResult(ParsersType)` type function so consumers can spell out the result type when needed.
