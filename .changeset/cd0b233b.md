Add `digit()` and `digits()` parsers under `parsers/digits/`. `digit()` matches a single ASCII decimal digit and returns its `u21` codepoint; `digits()` matches one-or-more digits and returns the borrowed byte slice from the input. Empty input yields `kind = .incomplete`; a non-digit at the cursor yields `kind = .syntactic` with the cursor unchanged.
