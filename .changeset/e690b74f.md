Add Tier B parsil-TS parity gap-fills (closes #118, #120):

- **`endBy(sep, p)` / `endByOne(sep, p)`** — terminator-style repetition: every item REQUIRES a trailing `sep` (no leniency for the last item like `sepEndBy` provides). Useful for parsing `;`-terminated statement lists where partial items are syntax errors.
- **`bit.intBe(n)` / `bit.intLe(n)`** — signed bit reads (1..=64 bits) returning `i64` with proper two's-complement sign-extension. Complements the unsigned `bit.bitsBe` / `bit.bitsLe`.
