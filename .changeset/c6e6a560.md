Add the standalone `chain(p, U, fn_chain)` combinator — free-function complement to `Parser(T).chain`. One-line delegate to the method form, so the two are guaranteed identical. The standalone reads more naturally than the method form when the parser is built inline (e.g. `chain(sequenceOf(.{...}), Result, build)`). Same value-dependent semantics: run `p`, hand its value to `fn_chain` to produce the next parser, then run that.
