Add Tier A parsil-TS parity gap-fills (closes #113-#117): 9 trivial parsers via `satisfy` and small primitives.

- **Char classes** (built on `satisfy`):
  - `hexDigit()` — `[0-9a-fA-F]`
  - `octDigit()` — `[0-7]`
  - `alphaNum()` — `[a-zA-Z0-9]`
  - `upper()` — `[A-Z]`
  - `lower()` — `[a-z]`
- **Negative lookahead**: `anyCharExcept(p)` — consume one byte unless `p` would match at the cursor (lookAhead-style savepoint, byte-level).
- **Position helper**: `index()` — return current byte offset without consuming. Useful inside `chain` / `apply` for capturing positions without `withSpan`.
- **Bit assertions** (under `bit.`): `zero()` / `one()` — assert specific bit value, consume it.
- **Raw byte read** (under `binary.`): `bytes(n)` — read exactly `n` bytes as a borrowed slice.

Also adds the previously-missing README subsections for `binary.*` and `bit.*` namespaces (oversight from the original PRs #110 and #111).
