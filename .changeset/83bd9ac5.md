Add `everythingUntil(stopP)` and `everyCharUntil(stopP)` — consume input up to (but not including) a sentinel parser. Both return the consumed slice borrowed from `state.input` (zero allocation). `everythingUntil` advances 1 byte per iteration; `everyCharUntil` advances by full UTF-8 codepoint width (with three failure kinds: `.incomplete` for EOF or truncated UTF-8, `.lexical` for invalid UTF-8 leading byte). Cursor lands at the start of `stopP`'s match — `stopP` itself is NOT consumed (caller can chain `.skip(stopP)` to consume it).
