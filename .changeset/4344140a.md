**Breaking:** rename the library and package to `knit`. The Zig
package name in `build.zig.zon` becomes `.knit`, the library
module is now `@import("knit")`, and the public barrel moves to
`src/knit.zig`. API surface (parser names, types, methods) is
unchanged.

Migration:

```diff
-const parsil = b.dependency("parsil_zig", .{ ... }).module("parsil");
-const P = @import("parsil");
+const knit = b.dependency("knit", .{ ... }).module("knit");
+const P = @import("knit");
```

The GitHub repo URL also moves to `salty-max/knit` (the prior
`parsil-zig` URL keeps working via GitHub's rename redirect, so
existing `zig fetch --save git+https://github.com/salty-max/parsil-zig`
keeps resolving — but new install instructions use the canonical
`knit` URL).
