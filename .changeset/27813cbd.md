Add the standalone `lookAhead(p)` combinator — non-consuming success, free-function complement to the `Parser(T).lookAhead()` method. Same semantics: returns `p`'s value (or err) but always restores the cursor to the entry position. Documented O(N)-on-repeat (each call re-parses).

**Breaking:** the existing `Parser(T).lookahead()` method is renamed to `.lookAhead()` for consistency with the camelCase convention used elsewhere in the API (`oneOf`, `noneOf`, `manyOne`, `sepBy`, `inContext`, `anyChar`, `whitespace1`). Update every `.lookahead()` call site to `.lookAhead()`.
