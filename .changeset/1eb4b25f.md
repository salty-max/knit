Add `recursive(T, thunk)` returning `Parser(T)` — define a parser that references itself (or another parser that does) via a lazy thunk, breaking construction-time cycles for recursive grammars like `expr = num | "(" expr ")"`. The thunk is invoked at each `parse(state)` call rather than at `recursive(...)` construction. Doc comment flags the left-recursion caveat (parsil-zig is recursive-descent — a left-recursive grammar will infinite-loop at parse time; restructure with `many` / `sepBy` or use right recursion).
