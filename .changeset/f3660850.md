Add `letter()` and `letters()` parsers under `parsers/letters/`. `letter()` matches a single ASCII letter (a-z or A-Z) and returns its `u21` codepoint; `letters()` matches one-or-more ASCII letters and returns the borrowed byte slice. ASCII-only by design — Unicode letters can be opted in via `satisfy(predicate, name)`. Empty input yields `kind = .incomplete`; a non-letter at the cursor yields `kind = .syntactic` with the cursor unchanged.
