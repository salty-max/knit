Add the standalone `between(left, p, right)` combinator, complement to the existing `Parser(T).between(left, right)` method. Same semantics — runs left, then p, then right, keeps only p's value — but spelled positionally for grammars where `between(L, P, R)` reads more naturally than `P.between(L, R)`. Types inferred from the parsers themselves.
